# キーボードショートカット

## コマンドヘルプ

`Ctrl+H` で、すべてのコマンドとキーボードショートカットの一覧を表示するコマンドヘルプ画面を開けます。コマンド名で絞り込み検索もできます。

## よく使うショートカット

| キー | 動作 |
|---|---|
| `Ctrl+F` | ファイル検索を開く |
| `Ctrl+H` | コマンドヘルプを開く |
| `Ctrl+P` | コマンドパレットを開く |
| `Ctrl+U` | ディスク使用量分析を開く |
| `Shift+J` | ジャンプ履歴（最近訪れたフォルダ）を開く |
| `Ctrl+Tab` | アクティブなペイン（左/右）を切り替え |

## カスタマイズ

キーボードショートカットは **設定 → Key Bindings** タブから変更できます。ファンクションキーの割り当ては **Function Keys** タブ、グローバルホットキー（アプリ非フォーカス時）は **Global HotKey** タブで設定します。
