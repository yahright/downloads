# FileCatalog Windows ベータ

外付けディスクや NAS を外していても、以前に登録・走査したファイルの名前やパスを探せる台帳です。指定した場所はテキストや Office 文書の本文も保存して検索できます。

## ダウンロードと起動

1. [リリース一覧](https://github.com/yahright/downloads/releases?q=filecatalog)から `FileCatalog-<version>-win-x64-portable.zip` と `.sha256` をダウンロードします。
2. ZIP を新しい空のフォルダーへ展開します。既存の版へ上書きしないでください。
3. `FileCatalog` フォルダー内の `FileCatalog.exe` を起動します。
4. 「場所を追加」で対象フォルダーを登録し、走査します。検索欄に語を入力して Enter または「検索」を押します。

Windows x64 版です。ARM64 Windows 11 でも x64 エミュレーションで検証しています。管理者権限・別途の VC++ ランタイム導入は不要です。未署名のため SmartScreen の確認が表示される場合があります。

## 使い方

- 空白は AND、半角 `|` は OR（例: `見積 | 請求 ext:pdf`）。プリセットで拡張子条件を追加できます。
- 外した場所も検索できます。ファイルを開くには元の場所を接続してください。
- 本文検索は場所ごとに有効化します。PDF の本文抽出には x64 対応の PDF IFilter が別途必要です。画像だけの PDF の OCR は行いません。
- ウィンドウの × はトレイへ隠します。終了はトレイメニューから行います。サービスが走査中なら GUI を閉じても続きます。「サービスも止めて終了」で両方を停止できます。
- 自動起動は任意です。アプリを固定のフォルダーへ置いてから設定してください。
- 台帳の既定保存先は `%LOCALAPPDATA%\FileCatalog\catalog.db`。ZIP の展開先とは別なので、更新時にも保持されます。
- 更新時はトレイから「サービスも止めて終了」を選び、新版を別フォルダーへ展開します。自動起動を設定済みなら新版で再設定してください。台帳を旧版へ戻す場合に備え、初回起動前に保存先フォルダーをバックアップできます。
- `fcat.exe` は CLI です。`fcat version`、`fcat status`、`fcat search 見積` などが使えます。

## ベータでの確認範囲

名前検索、OR・プリセット・履歴、Office 本文のオフライン検索と書き出し、GUI、サービス、HKCU 自動起動は自動試験で検証します。実物の NAS・外付けの切断、実アカウントの Dropbox、日本語 IME/DPI、PDF IFilter、Mac と Windows 間の取り込みは追加の実機確認が残ります。

ソースコードは非公開です。GitHub リリースの「Source code」は配布リポジトリの内容です。アプリ本体は上記のポータブル ZIP を選んでください。
