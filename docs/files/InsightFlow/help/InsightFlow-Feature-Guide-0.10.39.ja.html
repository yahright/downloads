InsightFlow 機能ガイド

ファイル作業を、ひとつの場所で。

探す・見比べる・整理する。初めての方へ、InsightFlow でできることを紹介します。

最初の3ステップ

01 / 開く

左右にフォルダーを開く

左に作業元、右に作業先を開きます。左右はそれぞれ別の場所やタブを持てます。

02 / 見る

ファイルを選んで中身を見る

プレビューで内容を確認。複数の項目をまとめて扱うときは「マーク」を付けます。

03 / 実行する

メニューやコマンドパレットで探す

Windows は Ctrl+P、macOS は Cmd+P。名前で操作や設定を探せます。キーは既定値で、変更できます。

画面で見る InsightFlow

Windows版の実際のUIをサンプルデータで描画した画面例です。フォルダー名・パスは説明用です。OSやテーマで見え方が異なります。画像をクリックすると拡大できます。

やりたいことから探す

一致する機能がありません。別の言葉で検索してください。

移動・表示

左右のペインで見比べる

左右に別々のフォルダーを表示し、タブで複数の場所を切り替えられます。移動元と移動先を同時に見ながら作業できます。

こんなときに ダウンロードした資料を、右側のプロジェクトフォルダーへ整理したい。

使い始めるには

左右それぞれでフォルダーを開きます。ナビゲーションロックを使うと、対応するサブフォルダーへ左右一緒に移動できます。

  • 他のペインにフォーカス — View > 他のペインにフォーカス
  • ナビゲーションロックの切り替え

移動・表示

開く前に中身を見る

選択したファイルの内容をプレビューで確認できます。画像・テキスト・PDFなど、対応する種類のファイルを確認しながら選べます。

こんなときに 似た名前の写真や資料から、目的の1件を見つけたい。

使い始めるには

ファイルを選び、プレビューを表示します。「バイナリでプレビュー」ではHex/ASCIIの確認、検索、位置ジャンプ、範囲コピーができます。別ウィンドウや固定プレビューも使えます。対応形式は環境により異なります。

  • ペインのプレビューの切り替え — View > ペインのプレビューの切り替え
  • ウィンドウプレビューの切り替え — View > ウィンドウプレビューの切り替え
  • ウィンドウプレビューを固定
  • バイナリでプレビュー — View > バイナリでプレビュー

移動・表示

よく使う場所へすぐ移動

お気に入り・ブックマーク・履歴で場所を覚えておけます。ロケーションランチャーには、よく使う移動先を登録できます。

こんなときに 毎回同じ深いフォルダーを何階層もたどる手間を減らしたい。

使い始めるには

移動メニューからお気に入りやブックマークを開きます。現在の場所を登録してから、次回は一覧から選びます。

  • お気に入りを表示 — Go > お気に入り > お気に入りを表示
  • ブックマークを表示 — Go > ブックマーク > ブックマークを表示
  • 履歴 — Go > 履歴

移動・表示

作業場所の組み合わせを保存

作業用のタブやペインの状態をワークスペースとして保存し、別の作業へ切り替えた後も呼び戻せます。

こんなときに 仕事の資料整理と写真整理で、使うフォルダー一式を切り替えたい。

使い始めるには

作業用のフォルダーを開いてからワークスペースを保存し、必要なときに開きます。

  • ワークスペースを保存... — File > ワークスペースを保存...
  • ワークスペースを開く... — File > ワークスペースを開く...
  • ワークスペースを管理... — File > ワークスペースを管理...

探す・集める

名前やサイズでファイルを探す

現在のフォルダー以下を再帰検索し、結果を名前・拡張子などで絞れます。結果ペインではサイズの下限・上限も指定できます。

こんなときに プロジェクト配下から10 MB以上のPDFを探したい。

使い始めるには

検索メニューから再帰検索を開きます。結果のサイズ欄に「10 MB」などを入力してEnterで適用します。サイズ指定時はフォルダーを除外します。「結果をクリア」は一覧を空にし、元ファイルを削除しません。

  • 再帰検索 — Search > 再帰検索

探す・集める

ファイルの中の言葉を探す

Grepでテキストの内容を検索できます。ファイル名が分からなくても、本文に含まれる言葉から候補を見つけられます。

こんなときに 設定ファイルやソースコードのどこに特定の名前が書かれているか調べたい。

使い始めるには

検索メニューのGrepを開き、検索語と対象範囲を指定します。結果から該当ファイルへ移動できます。「新しい検索」で前の結果を保持したまま、同じフォルダーを次の条件で検索できます。

  • Grep ウィンドウを開く — Search > Grep

探す・集める

下の階層もまとめて見る

フラット表示で下位フォルダーのファイルを一覧にまとめられます。階層を何度も開閉せずに全体を確認できます。

こんなときに 月ごとのフォルダーに分かれたファイルをまとめて見たい。

使い始めるには

対象の親フォルダーを開き、フラット表示を切り替えます。大きいフォルダーでは列挙に時間がかかることがあります。

  • フラットビューの切り替え

探す・集める

別々の場所のファイルを集める

仮想フォルダーは複数の場所への参照をまとめた一覧です。スマートフォルダーは保存した条件を開くたびに再評価します。

こんなときに 「最近更新した音声」などの条件で、繰り返し使う一覧を作りたい。

使い始めるには

仮想フォルダーを作って選択項目を追加するか、新しいスマートフォルダーで名前・種類・サイズ・日時などの条件を組み合わせます。元ファイルは移動しません。

  • 新しい仮想フォルダー — Tools > 仮想リスト > 新しい仮想フォルダー
  • 新しいスマート フォルダー... — Edit > 新しいスマート フォルダー...
  • 仮想フォルダーマネージャーを開く — Go > 仮想フォルダー

探す・集める

後で扱うファイルをシェルフへ

別の場所を見ながら、扱いたいファイルを一時的な一覧にためておけます。集めた項目を後でまとめてコピー・移動できます。

こんなときに あちこちのフォルダーから、送付する資料だけを集めたい。

使い始めるには

選択項目をシェルフに追加し、一覧を確認してから作業先を指定します。追加しただけではファイルは移動しません。

  • シェルフに追加 — Tools > シェルフ > 選択項目をシェルフに追加
  • シェルフ: 内容を表示 — Tools > シェルフ > シェルフを表示
  • シェルフ: 他のペインにコピー — Tools > シェルフ > シェルフを他のペインにコピー

整理・管理

マークしたファイルをまとめて操作

コピー・移動・削除などの基本操作を、マークした複数項目へまとめて行えます。対応する処理はジョブとして進捗を確認できます。

こんなときに 選んだ資料だけを別のフォルダーにコピーし、処理結果も確認したい。

使い始めるには

対象をマークし、コピーや移動を実行します。コピー確認では対象・作業先と、SCOPYの速度優先／安全優先または標準を選べます。Undoは設定で有効にした場合に限られ、すべての操作を戻せるわけではありません。

  • コピー — File > 他のペインにコピー
  • 移動 — File > 移動
  • ジョブを表示 — Tools > ジョブ > ジョブを表示
  • ファイル操作履歴... — Edit > ファイル操作履歴...

整理・管理

ファイル名をまとめて整える

一括リネームで、複数ファイルの名前をまとめて変更できます。繰り返し使うルールはプリセットとして扱えます。

こんなときに 写真や資料の名前を共通のルールでそろえたい。

使い始めるには

対象を選び、一括リネームの画面でルールと変更後の名前を確認して実行します。フォルダー内や下位階層を対象にする操作もあります。

  • 名前の一括変更 — File > 名前の一括変更

整理・管理

圧縮ファイルを閲覧・展開

ZIP・7zの中をフォルダーのように閲覧し、展開や圧縮を行えます。tar.zstの作成・展開にも対応します。

こんなときに 受け取ったZIPの中身を確認してから展開したい。

使い始めるには

アーカイブを開くか、ファイルメニューのアーカイブ操作を使います。7z・zstdには外部ツールが必要です。tar.zstはフォルダーとしての閲覧に対応しません。

  • フォルダーとして開く — File > フォルダーとして開く

整理・管理

容量を使っている場所を見つける

ディスク使用量を一覧やツリーマップで確認できます。大きなフォルダーやファイルを見つける入口になります。

こんなときに 空き容量が減った理由を、フォルダーごとの大きさから調べたい。

使い始めるには

ツールメニューからディスク使用量やツリーマップを開きます。ルート欄の下で1つ上・ボリュームのルート・フォルダー選択・パス編集を使い、対象を変えて新しいスキャンを開始できます。スキャンを途中で止めると見つかった結果を残しますが、未完了バナーが出た合計は全体の容量ではありません。

  • ディスク使用量の生データ表 — Tools > ディスク使用量
  • ディスク使用量ツリーマップ — Tools > ディスク使用量ツリーマップ
  • フォルダーサイズを計算

整理・管理

重複ファイルを見つける

重複候補を調べ、同じ内容のファイルを整理するための一覧を作れます。結果を見比べて、残すものを選びます。

こんなときに 複数のフォルダーにコピーした資料の重複を確認したい。

使い始めるには

ツールメニューから重複ファイル検索を開いて対象を指定します。結果を確認してから選択やごみ箱への移動を行います。

  • 重複ファイルを検索 — Tools > 重複ファイルを検索

整理・管理

2つのフォルダーの差を整理

フォルダーの差分を確認し、同期方針に合わせて処理できます。比較はファイルサイズと更新日時を使います。

こんなときに 作業用フォルダーから保存先へ、追加・変更したファイルを反映したい。

使い始めるには

ツールメニューのフォルダー同期を開き、比較元・比較先・同期方式を確認します。削除を含む方式では差分をよく確認してから実行します。

  • フォルダーの同期 — Tools > フォルダーの同期

整理・管理

ファイルのハッシュを計算・照合

チェックサムでファイル内容を数値として比較できます。受け取ったファイルやコピーしたファイルの照合に使います。

こんなときに 配布元のハッシュ値とダウンロードしたファイルが一致するか調べたい。

使い始めるには

対象を選択し、チェックサムの計算または検証を実行します。比較する値と同じアルゴリズムを選びます。

  • チェックサムを計算...
  • チェックサムを検証...

開発・連携

Gitの変更と履歴を見る

Git管理下のフォルダーで変更状態を確認し、Gitウィンドウから差分・履歴やステージ操作などを扱えます。

こんなときに 編集したファイルを確認してから、コミットする変更を選びたい。

使い始めるには

リポジトリを開いてGitウィンドウを表示します。Gitの利用には環境側の準備が必要です。リモートへの操作は接続先とブランチを確認して実行します。

  • Git ウィンドウを開く — Git > Git ウィンドウ
  • Git すべてステージ — Git > Git すべてステージ
  • Git コミット — Git > Git コミット

開発・連携

今いるフォルダーでコマンド実行

ペイン下の1行コマンドバーからシェルのコマンドを実行できます。外部ターミナルや登録した外部ツールも開けます。

こんなときに ファイル一覧を見たまま、ビルドや変換のコマンドを実行したい。

使い始めるには

Ctrl+Shift+T（macOSはCmd+Shift+T）でコマンドバーを表示します。アクティブペインの場所で実行し、終了後は両ペインを再読込します。Shift+Enterで外部ターミナルへ渡せます。

  • コマンドバー: 表示切替 — View > コマンドバーを表示
  • ここでターミナルを開く — Tools > ターミナル > ここでターミナルを開く
  • 外部ツールを管理 — Tools > 実行 > 外部ツールを管理

開発・連携

ファイルを見ながらAIに相談

右側のAIチャットで、現在のフォルダーやマークしたファイルを文脈として相談できます。AIが返したファイル一覧はシェルフやマークに利用できます。

こんなときに 選んだ資料について相談し、候補のファイルを一覧にまとめたい。

使い始めるには

設定のAI Chatを有効にし、対応するエージェントを別途導入・認証します。AIチャットは既定でOFFです。送信前に文脈のチップを確認し、不要な項目は外します。AIによるInsightFlow操作の範囲は設定で選べます。

  • AI チャット: パネルを切り替え — View > AI チャットを表示

整理・管理

長い処理の進み具合を確認

コピーや検索などのジョブを一覧で見られます。対応する処理では一時停止・再開・キャンセルや失敗分の再試行ができます。

こんなときに 長いコピーの完了を待ちながら、別のフォルダーを見たい。

使い始めるには

ジョブ画面で処理を選択し、進捗・詳細・結果を確認します。使える操作はジョブの種類と状態で異なります。

  • ジョブを表示 — Tools > ジョブ > ジョブを表示
  • 失敗分のみ再試行 — Tools > ジョブ > 失敗分のみ再試行

設定・ヘルプ

自分に合う表示と操作にする

テーマ・表示列・キーバインド・外部ツール・右クリックメニューなどを設定できます。設定の場所もコマンドパレットから検索できます。

こんなときに よく使う操作をキーに割り当てたり、見やすい表示へ変えたい。

使い始めるには

設定を開くか、コマンドパレットに項目名を入力します。まず既定値で使い、必要なものから変更できます。

  • 設定 — Tools > 設定
  • コマンドパレット — Help > コマンドパレット
  • ダーク/ライトテーマの切り替え — View > テーマ > ダーク/ライトの切り替え

設定・ヘルプ

使い方と新しいバージョンを確認

このガイドで機能を知り、コマンドヘルプやAI向け説明書で詳しい操作を調べられます。更新の確認もヘルプメニューにあります。

こんなときに 操作の名前や設定場所を調べたい。新しい版が出たか確認したい。

使い始めるには

ヘルプメニューから各項目を開きます。自動確認が有効な場合は、起動時に加えて約4時間ごと（最大5分のずれ）に更新を再確認します。通知後の適用は更新画面から行います。

  • 機能ガイド — Help > 機能ガイド
  • コマンドヘルプの切り替え — Help > コマンドヘルプ
  • AI 用ヘルプファイルを開く — Help > AI 用ヘルプファイルを開く…
  • 更新を確認 — Help > 更新を確認
