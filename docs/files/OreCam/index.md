# OreCam 0.2.0 Windows Preview

Windows 11 向けの録画アプリです。WPF の操作画面からディスプレイ、ウィンドウ、音声のみの録画を選び、開始・一時停止・再開・停止を操作できます。

## ダウンロード

| PC | ZIP | 検証用ファイル |
| --- | --- | --- |
| Intel・AMD (x64) | [x64 ZIP](https://github.com/yahright/downloads/releases/download/orecam-v0.2.0/OreCam-0.2.0-win-x64-portable.zip) | [SHA-256](https://github.com/yahright/downloads/releases/download/orecam-v0.2.0/OreCam-0.2.0-win-x64-portable.zip.sha256) |
| Arm (ARM64) | [ARM64 ZIP](https://github.com/yahright/downloads/releases/download/orecam-v0.2.0/OreCam-0.2.0-win-arm64-portable.zip) | [SHA-256](https://github.com/yahright/downloads/releases/download/orecam-v0.2.0/OreCam-0.2.0-win-arm64-portable.zip.sha256) |

ZIP を展開して `OreCam.exe` を起動してください。.NET Desktop Runtime と録画 CLI を同梱しています。実行ファイルは署名なしです。
