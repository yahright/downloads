# RepoSyncTool Windows ベータ

複数の Git リポジトリの状態確認・同期と、個別リポジトリの Git 操作を行うアプリです。

## ダウンロードと起動

1. [Windows ベータ配布ページ](https://github.com/yahright/downloads/releases?q=reposynctool&expanded=true) で、お使いの CPU に合う `win-x64` または `win-arm64` の `portable.zip` をダウンロードします。
2. 新しい空のフォルダーへ展開し、`RepoSyncTool.exe` を起動します。.NET の追加インストールは不要です。
3. Git 2.35 以上を別途インストールしてください。Git が PATH にない場合は、⚙ →「Git 実行ファイル…」で実行ファイルを指定します。
4. 「＋ 新規 ▾」から URL からクローン、リモートリポジトリ（GitHub）の作成、既存のローカルリポジトリの追加、ローカルリポジトリの作成、フォルダのスキャン、リポジトリグループの作成を選びます。初回の一覧は空です。フォルダーを継続的に監視して登録したい場合は ⚙ →「フォルダ監視（自動登録）…」を設定します。

Windows 版は未署名ベータです。ダウンロード時や初回起動時に Windows の警告が表示される場合があります。ZIP と同名の `.sha256` でダウンロードの SHA-256 を照合できます。

## 主な操作

- 一覧でブランチ・変更数・未取得／未Push件数を確認し、検索や左バーで絞り込みます。ダブルクリックまたは「開く」で Git 画面を開きます。「状態更新」はローカル確認、「すべて Fetch」はリモート情報の取得です。
- 自動同期の対象は一覧の右クリックから ON/OFF にし、その場で保存します。未設定のリポジトリは自動同期の対象外です。
- 一括 Sync は追跡先を取得し、fast-forward 可能なリポジトリだけを更新します。未コミット変更・競合・履歴分岐などは理由付きで保留します。
- リポジトリを開くと、履歴・ブランチ・差分、stage/unstage、commit、fetch/pull/push、stash、merge/rebase などを利用できます。
- tracked テキスト（UTF-8・Shift_JIS・EUC-JP）の差分で行・ハンクをチェックし、部分 stage/unstage ができます。履歴は複数ブランチで絞り込めます。
- 変更ファイルを選び、右クリック →「Revert（HEADの内容へ戻す）…」で、ステージ済みと未ステージの変更をまとめて取り消せます。差分ファイルメニューからも実行できます。削除は復元、リネームは元の名前に戻し、ステージ済みの追加ファイルは削除します。未追跡・競合・submodule・symlinkは対象外です。確認後に実行し、操作履歴の「元に戻す」（Ctrl+Z）で内容とステージ状態を復元できます。
- 差分見出しの「⤢」でファイル一覧と差分を別窓に移し、1列・左右・自動表示を切り替えられます。長いファイル名は省略し、ホバーで全文を表示します。
- 差分ビュー上部の「文字コード」で自動・UTF-8・Shift_JIS（CP932）・EUC-JPを選んで読み直せます。全体表示・前後に展開した行にも反映し、選択はリポジトリごとに記憶します。
- 履歴のコミットメッセージ・注釈とファイル一覧の間をドラッグして高さを調整できます。位置は次回も復元し、差分ウィンドウでも使えます。
- ブランチの右クリックでお気に入りを登録できます。履歴の作者は「自分／特定の人／その他」で色分けし、⚙ →「作者の色分け…」で変更できます。
- 「ブランチ一覧」で最新コミット日時・コミッタ・件名を確認し、選択したブランチを非表示にできます。ブランチ自体は残り、履歴や候補から外れます。「非表示も表示」をオンにして選び直すと再表示できます。設定はリポジトリごとにこのPCへ保存します。
- 「表示ブランチを選択…」の「このコミットを含むブランチ」で、選択中または貼り付けたコミットを含むブランチだけにチェックを付け直せます。
- ブランチ作成・チェックアウト・チェリーピック後の表示連動は既定ONです。作成・実行画面や ⚙ →「ブランチ操作後の表示」でOFFにすると、表示中のブランチ選択を保ちます。
- チェリーピックの計画で「Edit（Amend で編集）」を選ぶと、取り込んだコミットで停止して Amend が自動で ON になります。「変更ファイル」のチェックや Git 画面の差分で中身を選び、説明を直して「Amend して続行」で確定します（通常の Amend ボタンも利用可）。作者・作者日時は保持します。除外した元の変更は退避して捨てます。
- チェリーピックの計画で［ファイル｜コミット］に切り替えると、複数コミットをファイル単位で編集できます。行がファイル、列が作るコミットで、変更を別の列へ移す・分ける・まとめる・持っていかないを選べます。競合の予測された行は「ここで解決する」で事前に解決し、「最終確認」タブで元コミットのスカッシュ結果と比べてから実行します。
- ファイル表示のコミット番号を選ぶと、下部のファイル一覧と右側の差分も切り替わります。「選択コミットのファイルだけ」で行を絞り込み・解除できます。ファイル名のチェック、Ctrl/Command+クリックやShift+クリックで複数選択し、前後へまとめて移動できます。一括移動は1回の「元に戻す」で戻せます。折りたたんだフォルダにも列ごとの変更件数が残り、各ファイルには元コミット数が表示されます。右側の操作ボタンは、長い説明をスクロールしている間も下端に表示します。
- ファイル名列の右端をドラッグすると幅を広げられます。列のヘッダにはファイル数と追加・削除行数が表示され、移動した変更は紫系の色と「↔」、フォルダの集計は灰色の「計 N 件」で区別します。行数は元コミットの変更の合計です。
- 列ヘッダのチェックかCtrl／Command＋クリックで、離れたコミットも複数選択できます。Shiftは範囲、Ctrl／Command＋Shiftは範囲を追加します。選択した列のファイルを下部にまとめて表示し、それらの列だけを1つに結合できます。
- 結合元の番号が多い列は「#1〜#12」などの範囲や省略表記にし、全番号はホバーで確認できます。「元コミットの説明」タブでは各元コミットのメッセージ全文・番号・SHA・作者・日時を参照でき、移動・結合・計画の説明編集のあとも原文が残ります。右側の片・列の詳細のボタンからも開けます。
- 新しいチェリーピックの計画は毎回初期状態で開きます。前回の編集を使うときだけ「前回の計画を復元」を選びます。「計画を初期状態に戻す」で移動・除外・結合・メッセージ・競合解決・確認印をリセットでき、Undoもできます。取り込み途中の同じ実行を開き直す場合は、その進行状態を保ちます。
- 下部の変更ファイル一覧でパス検索・ツリー・種類／拡張子による絞り込み・並び替え・行数と増減バー・パスのコピーを利用できます。右側の差分では左右／一列・全体・空白無視／記号表示・検索（Ctrl+F、F3）・変更箇所への移動（F7、Shift+F7）・別窓・コピーを利用できます。表示対象は選択した元コミットの変更です。
- マージでは、Gitが許可する場合は無関係な未コミット変更を残して進められます。ローカル変更を上書きする場合などはGitが理由を表示して拒否します。
- 履歴の検索欄に「ファイル名に含む」を追加しました。「作者 ▾」は複数選択でき、外すまで残る緑のチップでリポジトリごとに保存します。
- CLI は `RepoSyncTool.exe --cli`、stdio MCP は `RepoSyncTool.exe --mcp` から利用できます。

## 自動同期（任意）

一覧の右クリックで対象リポジトリの自動同期をONにし、⚙ →「自動同期…」から登録します。監視フォルダーを利用する場合は、同梱の `register-auto-sync-windows.bat` に対象フォルダーを渡す方法も使えます。通常ユーザーで登録してください。

```bat
register-auto-sync-windows.bat "C:\Users\yourname\source\repos"
```

ログイン時と現地時刻 0/6/12/18 時に実行します。解除は GUI または `unregister-auto-sync-windows.bat` から行います。自動 push は既定 OFF で、必要なリポジトリだけ明示設定します。移動後は再登録してください。

## AI チャット（0.17.0〜）

1. 利用する Claude Code / Codex CLI / GitHub Copilot CLI を別途導入し、ターミナルでログインします。
2. 一覧または Git 画面の ⚙ →「AI チャット…」で機能と利用する AI を ON にします。自動検出と接続テストを利用できます。チャット上部と設定画面からモデル・エフォートを選べ、AIごとに保存されます。Codex / CopilotはCLIから候補を取得し、ClaudeはSonnet / Opus / Haikuの別名を選べます。モデルIDの直接指定も可能です。「CLIの既定」でCLI側の設定に戻り、変更は会話を保って次の送信から反映されます。Claude の接続テストは版の確認までで、ログイン・trust は初回送信時に確認します。
3. Git 画面の「✦ AI」（Ctrl+Shift+I）で右側のパネルを開き、AI のタブを選んで送信します。Enter で送信、Shift+Enter で改行、応答中の「■ 停止」で止めます。パネルを閉じても処理は続き、Git 画面を閉じると終了します。
4. `/review`、`/explain`、`/message`、`/summary` を入力するか、パネルの各ボタンを使えます。履歴の右クリックとコミット欄にも入口があります。「渡したもの」で送信した状態・差分を確認できます。ロックファイル・バイナリ・上限を超える差分本文は添付を省きます。

初期アクセスは「読むだけ」です。「注釈・確認済みも」ではアプリ内の注釈などを変更でき、「Git 操作（確認つき）」では計画の確認カードから Git を操作できます。AI の確認済みは紫の印で、人の未確認として残します。ユーザーの記録を変えるときは確認し、変更後は会話内の「元に戻す」を利用できます。その後に記録が変わっている場合は、上書きして戻さず理由を表示します。

Git の確認カードは種類ごとに「今回だけ／この会話／常に許可」を選べます。危険な操作は内容確認のチェックが必要です。常に許可は ⚙「AI チャット…」から解除できます。送信先を変えた push は再確認します。Git 操作の取り消しは既存の「操作履歴と取り消し…」を使います。

会話はこの PC のアプリデータへ保存できます（設定で OFF にできます）。過去の会話は表示を復元し、新しい AI セッションとして続けます。アプリ内の会話を削除しても各 CLI 側に保存された会話は残ります。AI 機能はローカル専用です。シェルの直接実行とファイル編集は許可しません。

## 0.20.0の追加操作

「＋ 新規」→「GitHubから探してクローン」で、既存リポジトリを取得できます。認証済みのGitHub CLIを使用します。

Git作業画面の設定に追加したメニューから、PR作成とCI結果、サブモジュール・サブツリー・LFS、パッチ適用と連番出力、テンプレート、表示上限と日時、グローバル無視リスト、ツールバー、カスタム操作、作者別統計を開けます。マージ・タグ・フェッチの条件は各操作画面で指定します。

## 保存先と更新

設定・Host 台帳・バックアップ・自動同期のログは、本人の `%LOCALAPPDATA%\RepoSyncTool` 配下に保存します。Git の認証には既存の Git 設定を利用します。

0.8.0 以降はアプリ内で更新できます。起動時と 6 時間ごとに新しいバージョンを確認します。⚙ →「更新を確認…」で変更点を見て「ダウンロードして更新」を押すと、ZIP をダウンロードして SHA-256 を照合し、アプリを終了して同じフォルダーの中身を置き換え、起動し直します（実行中の Git 操作は Git Host で最後まで終わってから置き換えます）。ネットにつながらない PC では、手でダウンロードした ZIP を「ZIPから更新…」で指定できます（同じ場所に `.sha256` があれば照合します）。置き換えに失敗したときは元のファイルに戻して起動し、`%LOCALAPPDATA%\RepoSyncTool\logs\update.log` に理由を記録します。書き込めないフォルダー（Program Files など）に置いた場合は自動更新できません。自動確認は更新画面のチェックで OFF にできます。

0.7.0 以前の版からは、アプリを閉じて新しい ZIP を別の空フォルダーへ展開してください。自動同期を登録している場合は解除してから新しい配置で再登録します。設定ファイルを旧配布フォルダーからコピーする必要はありません。

## ベータでの確認事項

最低対応 OS、x64 実機、日本語 IME/HiDPI、別ユーザー間の IPC 拒否、実アカウントでの SSH/GCM/署名、実 TaCM の Mac・Windows 間配送、自動同期のログイン・スリープ復帰は追加受入が残ります。
