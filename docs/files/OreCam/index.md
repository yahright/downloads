# OreCam 0.1.0 Windows CLI Preview

Windows 11 でディスプレイ、ウィンドウ、指定領域を録画するコマンドライン版です。システム音声やマイクを録音でき、異常終了した録画の回復にも対応します。

## ダウンロード

| PC | ZIP | 検証用ファイル |
| --- | --- | --- |
| Intel・AMD (x64) | [x64 ZIP](https://github.com/yahright/downloads/releases/download/orecam-v0.1.0/OreCam-0.1.0-win-x64-portable.zip) | [SHA-256](https://github.com/yahright/downloads/releases/download/orecam-v0.1.0/OreCam-0.1.0-win-x64-portable.zip.sha256) |
| Arm (ARM64) | [ARM64 ZIP](https://github.com/yahright/downloads/releases/download/orecam-v0.1.0/OreCam-0.1.0-win-arm64-portable.zip) | [SHA-256](https://github.com/yahright/downloads/releases/download/orecam-v0.1.0/OreCam-0.1.0-win-arm64-portable.zip.sha256) |

ZIP を展開し、そのフォルダーの PowerShell で `./orecam-winrec.exe --help` を実行してください。署名なしのプレビューです。GUI とカメラ録画は準備中です。
