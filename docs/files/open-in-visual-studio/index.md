# Open in Visual Studio

Windows 版 VS Code で表示中のファイルを、起動中の Visual Studio で開く拡張です。カーソルの行と列も引き継ぎます。

- [最新版 0.1.0 の VSIX をダウンロード](https://github.com/yahright/downloads/releases/download/open-in-visual-studio-v0.1.0/open-in-visual-studio-0.1.0.vsix)
- [リリースノートと SHA-256](https://github.com/yahright/downloads/releases/tag/open-in-visual-studio-v0.1.0)
- [配布情報 JSON](latest.json)

1. VS Code の拡張機能ビューで「VSIX からのインストール」を選び、ダウンロードした VSIX を指定します。
2. Visual Studio のエディターを開いておきます。両方の IDE を同じ Windows ユーザー・管理者権限で実行してください。
3. VS Code で対象ファイルを表示し、コマンドパレットから **Open in Visual Studio** を実行します。
