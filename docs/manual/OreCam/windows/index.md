# OreCam Windows Preview

Windows 11 向けの録画アプリです。Intel・AMD の PC は x64、Arm ベースの PC は ARM64 の ZIP を選んでください。ZIP に .NET Desktop Runtime が含まれています。実行ファイルは署名なしです。

## 録画する

1. ZIP をフォルダーに展開し、その中の `OreCam.exe` を起動します。
2. ディスプレイ、ウィンドウ、音声のみのいずれかを選びます。対象一覧の「更新」で、新しく開いたウィンドウを表示できます。
3. 必要に応じてシステム音声とマイクを選びます。「音声をミックス」を選ぶと、両方の音声が1トラックになります。
4. 「録画開始…」を押し、保存ファイル名を指定します。画面・ウィンドウは MP4、音声のみは M4A です。
5. 必要に応じて「一時停止」と「再開」を使います。「停止」を押すと保存が完了します。「保存先を開く」でファイルのフォルダーを開けます。

1回の録画は最大1時間です。録画中に OreCam の画面を閉じると、その時点で録画を終了して保存します。

## コマンドラインを使う

同じフォルダーに `orecam-winrec.exe` が入っています。領域指定の録画や録画ファイルの確認・回復の手順もあります。 [CLI の使い方](../)
