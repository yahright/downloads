AppCat 配信サーバー（Windows）

1. ZIPをフォルダに展開し、setup-server.bat をダブルクリックします。
2. Windowsの確認画面が出たら「はい」を選びます（LAN接続の許可）。
3. 「配信を開始します」と出たら、その画面を開いたままにします。
4. 表示されたVMのURLを、受け取るPCのAppCatの「置き場」に設定します。
   localhost ではなく、VMのIPアドレスのURLを使ってください。

GitHubのアカウント・ログイン・トークンは不要です。
初回取得・配布物の更新時には、公開GitHubへのインターネット接続が必要です。

保存先: %LOCALAPPDATA%\AppCatServer
次回起動: 保存先の start-server.bat
配布物の更新: 保存先の sync-server.bat
停止: 配信画面で Ctrl+C、またはウィンドウを閉じる
エラーログ: 保存先の logs フォルダ

受け取るPCからつながらない場合:
- http://VMのIP:8765/catalog.json をブラウザで開いて確認します。
- VMのネットワークはLANから到達できる設定にします（ブリッジ接続など）。
- 許可をキャンセルした場合は、バッチを再実行して「はい」を選びます。

Windows x64 / ARM64 向け。Windows起動時の自動起動は設定しません。
